## Blender記事市場について

**誰でもBlenderの物づくりの記事を書けて、初心者や作り方に悩んでいる人を上級者や有志が助けるコミュニティ型共有プラットフォームです。**

## 注意⚠️

**本サイトは開発中のデモ（ポートフォリオ）作品です。ユーザー登録や記事投稿などの機能はお試しいただけますが、入力されたデータは予告なく削除される場合があります。また、実在する人物や団体、実際のサービスとは一切関係ありません。**

## 主な機能

- セクション形式で記事を簡単に書けます。画像を追加してより詳しい内容にする事も出来ます！
- 記事にいいねやコメントなどを残して、記事の作者を応援しよう！
